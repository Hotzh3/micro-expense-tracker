# J Tap

J Tap is a minimal iPhone app concept for capturing micro-expenses in under 10 seconds. It is designed around a fast manual flow, with Back Tap and Shortcuts/App Intents planned later, so users can log small spending moments without friction.

## Problem Solved

Micro-expenses add up quickly, but they are easy to forget. J Tap gives users a fast, low-friction way to record small purchases before the details disappear.

## MVP

- Quick expense capture with amount and category
- Minimal dashboard with weekly and monthly placeholders
- Simple history screen
- Placeholder insights for spending patterns
- Clean black-and-white visual system

## Planned Features

- Back Tap shortcut entry
- App Intents and Shortcuts support
- SwiftData persistence
- Weekly and monthly charts
- Optional text parsing for pasted or shared expense details
- OCR or other capture helpers only if technically viable later

## Tech Stack

- Swift
- SwiftUI
- SwiftData later
- App Intents later
- Shortcuts later
- Swift Charts later
- XCTest or Swift Testing later

## Current Status

Product definition, iOS app foundation, and minimal design system skeleton are in place. This repository does not yet contain a full Xcode project.

## Roadmap

1. Phase 0: Product definition and technical constraints
2. Phase 1: iOS app foundation
3. Phase 2: Minimal design system skeleton

## Privacy Note

J Tap is designed to avoid depending on third-party bank notification access. The MVP focuses on manual entry and local-first data handling. Any future import or parsing features should be opt-in and privacy-conscious.

## Portfolio Positioning

This project can be presented as a product and iOS systems case study: defining a focused user problem, designing a minimal capture flow, establishing a premium visual language, and preparing the codebase for native iOS features like App Intents and Back Tap.
