## Description Draft

Pocket Leak is a privacy-first micro-expense tracker for iPhone.

Capture small spending leaks quickly with Quick Add, manual parsing for pasted or shared transaction text, weekly and monthly goals, Dashboard totals, History filters, Insights charts, widget summaries, local reminders, and export options.

Pocket Leak keeps data on device and does not read notifications from other apps.
