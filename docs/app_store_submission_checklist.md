# App Store Submission Checklist

Use this before the first TestFlight upload and again before App Store submission.

## Store Assets

- [ ] App icon is final and matches the brand.
- [ ] Screenshots exist for iPhone form factor(s) the store will request.
- [ ] Optional preview video is not required for the first release.

## Metadata

- [ ] App name is `Pocket Leak`.
- [ ] Subtitle is finalized.
- [ ] Promotional text is finalized.
- [ ] Description is finalized.
- [ ] Keywords are tuned for finance / budgeting / expenses.
- [ ] Support URL is real and reachable.
- [ ] Marketing URL is real and reachable or intentionally omitted.
- [ ] Copyright line is correct.

## Privacy

- [ ] Privacy nutrition labels are prepared.
- [ ] Data collection summary matches the app behavior.
- [ ] Privacy policy / privacy summary is published if needed.
- [ ] The store listing says the app does not read other apps' notifications.
- [ ] The store listing says core data stays local on device.
- [ ] Exported files are described as user-generated local exports.

## Review Information

- [ ] Age rating is selected correctly.
- [ ] Export compliance answers are complete.
- [ ] Sign-in requirements are documented if a future cloud feature is added.
- [ ] Demo account details are available only if the app later needs login.
- [ ] Notes for App Review mention the main flows to test.

## Distribution

- [ ] Archive succeeds with the shared `JTap` scheme.
- [ ] Upload to App Store Connect succeeds.
- [ ] TestFlight build processes successfully.
- [ ] Internal testers can install the build.
- [ ] External beta review is completed before using a public link.

## Manual QA Before Upload

- [ ] Quick Add works.
- [ ] Parse Text works.
- [ ] Goals work.
- [ ] Widgets render.
- [ ] Share Extension hands off text.
- [ ] PDF / CSV / JSON export works.
- [ ] Local notifications are permission-safe.
- [ ] Back Tap shortcut opens Quick Add.
- [ ] App Lock / Privacy Mode work if enabled.

## Future Notes

- [ ] If login is added later, document demo credentials here.
- [ ] If cloud sync is added later, update the privacy summary and data collection answers.
