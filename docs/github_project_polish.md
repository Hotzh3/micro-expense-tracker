# GitHub Project Polish Checklist

Use this as the final repo cleanup list before sharing Pocket Leak as a portfolio project.

## Documentation

- README complete and easy to scan
- product brief written clearly
- design direction documented
- roadmap easy to understand
- demo script available
- screenshot plan available
- privacy summary clear
- technical constraints explicit
- portfolio case study available

## Media

- screenshots prepared or placeholder paths documented
- demo video recorded
- images optimized for GitHub
- captions or alt text ready

## Release Notes

- short project summary
- what was built
- what is local-only
- what is still pending
- why the app is a good portfolio example

## GitHub Metadata

- repo topics:
  - `swiftui`
  - `ios`
  - `personal-finance`
  - `local-first`
  - `xcodegen`
- issue labels:
  - `docs`
  - `bug`
  - `performance`
  - `design`
  - `demo`
- project board optional if task tracking helps, but not required for a portfolio repo

## Repo Presentation

- keep the README focused on the product story
- avoid dead links
- keep screenshots aligned with the demo dataset
- make the local-first privacy story obvious in the first screenful

## Free Distribution Reminder

GitHub can show the source and documentation, but it does not install the app on an iPhone with a single click. A real iPhone build still needs a Mac and Xcode, and TestFlight or App Store distribution still needs the Apple Developer Program.
