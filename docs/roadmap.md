# Roadmap

## Phase 0 - Product Definition

- Define the problem, user, scope, and non-goals
- Document iOS notification limitations
- Establish the product direction and portfolio narrative

## Phase 1 - iOS App Foundation

- Create the SwiftUI app shell
- Define core models and views
- Prepare a clean folder structure for a future Xcode project

## Phase 2 - Minimal Design System Skeleton

- Build the black-and-white theme foundation
- Add reusable card, button, pill, metric, and empty-state components
- Style the main screens with placeholders and sample data

## Phase 3 - Persistence

- Add SwiftData storage
- Save and load expenses locally
- Preserve the quick-add experience

## Phase 4 - Entry Automation

- Add App Intents
- Connect Quick Add to Shortcuts
- Prepare for Back Tap invocation

## Phase 5 - Capture Enhancements

- Explore pasted text parsing
- Consider OCR if it is technically viable
- Keep advanced imports optional and privacy-aware

## Phase 6 - Insights

- Add weekly and monthly charts
- Surface trends and spending patterns
- Highlight top categories and changes over time

## Phase 7 - Polish and Ship

- Refine motion and hierarchy
- Add tests
- Prepare App Store and portfolio materials
